# 09｜Observation：工具返回了什么，不等于 Agent 理解了什么

Action 之后，环境会返回结果。

这一步看起来很简单：把 Tool Result 塞回模型就行。

实际系统里，很多错误就发生在这里。

## Observation 不只是原始返回值

例如一次数据库查询返回 5000 行。

Agent 真正需要的可能是：

- 查询是否成功；
- 是否出现异常分布；
- 哪几条记录值得继续查；
- 结果是否足以验证当前假设。

原始 Result 是事实来源，Observation 是**当前 Loop 对这个结果的有效表示**。

## 三种常见错误

### 丢结果

工具已经给出错误信息，但程序没有正确传回模型。

### 误解结果

空列表被理解成“没有问题”，其实可能是查询条件错了。

### 噪声过多

完整日志回灌 Context，真正重要的几行被淹没。

## Observation 要保留可验证性

如果 Observation 经过摘要，最好保留原始来源或引用位置。

否则模型后面基于摘要做出结论，却无法回查。

## 地图坐标

Action 改变世界。

Observation 告诉 Agent 世界发生了什么。

二者之间任何失真，都会让后续 Decision 建立在错误现实上。
