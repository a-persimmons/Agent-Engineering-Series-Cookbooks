# 13｜Role：角色设定到底有什么用

“你是一位世界顶级专家”是最流行、也最容易被滥用的提示词写法之一。

问题不是 Role 没用，而是很多 Role 没有携带有效信息。

## 有效 Role 应该改变什么

角色至少应该改变以下一种东西：

- **视角**：从谁的立场判断。
- **责任**：必须对什么结果负责。
- **知识边界**：应该关注哪些领域。
- **决策边界**：哪些事情可以决定，哪些必须升级。
- **表达方式**：结果写给谁看。

例如：

> 你负责上线前代码审查。优先识别会造成数据损坏、权限绕过和不可恢复故障的问题；风格问题不作为阻断项。

真正起作用的不是“高级代码专家”，而是责任和优先级。

## 一个反例

> 你是一位拥有 30 年经验、世界顶级、极其严谨的架构师。

如果后面没有任务目标、系统背景和评审标准，这段话几乎无法替代缺失的信息。

## Persona 什么时候有价值

写作、教学、客服等任务中，Persona 可以稳定语气与受众适配。

但仍然应该具体：

> 面向第一次接触 Docker 的 Java 开发者。保留专业术语，但首次出现时用一句话解释。

这比“像老师一样耐心”更可执行。

## 挂回地图

Role 往往同时影响 **Goal、Constraints 和 Output**。

把它当成信息压缩方式，而不是“给模型加智力 Buff”，就不会再滥用角色设定。
